## 2024-06-19 - [Micro-UX & Separation of Concerns]
**Learning:** For data-intensive applications, row-level selection in tables significantly enhances usability. Additionally, separating the authentication entry point from the main application dashboard allows for cleaner JavaScript modularization and better initial page load.
**Action:** Always implement row-level selection for data tables and prioritize modularizing JS into core API, Auth, and App layers.
